## 如何提供给不同 AI

1. 填写并提交真实内容，删除不适用的示例。
2. 向支持联网读取的 AI 提供本仓库链接或 [README 原文链接](https://raw.githubusercontent.com/scofice/ai-personal-profile/main/README.md)，明确要求读取。
3. 无法联网的 AI，可直接粘贴 README 内容或上传该文件。
4. 可使用这段提示：

   > 请先读取我的个人档案，用作本次任务的背景。示例和占位符不能作为事实；如档案与我当前的明确指令冲突，以当前指令为准。无法读取链接时请告诉我。

仓库不会自动同步到所有 AI；每个 AI 是否读取及何时更新，取决于其能力和你的操作。

## 本地同步与版本记录

首次克隆：

```bash
git clone https://github.com/scofice/ai-personal-profile.git
cd ai-personal-profile
```

每次编辑前同步，完成后提交并推送：

```bash
git pull --ff-only
# 编辑 README.md 后，先检查变更
git diff
git add README.md
git commit -m "docs: 更新个人档案"
git push
```

Git 原生记录每次提交，无需另开版本记录开关。只有已提交的修改会进入历史；提交并推送后，GitHub 才能显示该版本。推送需要拥有本仓库写权限的 GitHub 身份验证。

- 网页查看：打开文件的 **History**，或仓库的 **Commits**。
- 本地查看：运行 `git log --oneline`；用 `git show 提交ID` 查看某次修改。
- 回退已提交修改：先确保工作区干净并同步，再运行以下命令；将 `提交ID` 替换为实际需要撤销的普通提交。`git revert` 会创建一条新的撤销记录，保留原有历史。

```bash
git status
git pull --ff-only
git revert 提交ID
git push
```
